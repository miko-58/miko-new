# ユーザー同士のチャット

地図またはリストでヒーローを選び「チャットする」で開始します。
会話画面の「やり取りを終了」は双方が利用でき、両者が次の相手と話せるようになります。
同じ相手との再開では同じ部屋と履歴を使います。終了した会話は一覧に残りますが、再開するまでは送信できません。

## 保存先と制限

- `directChats/{pairId}`: 2人のUID、表示名、active/closed、作成・更新日時。
- `directChats/{pairId}/messages/{messageId}`: 送信者UID、本文、送信日時。
- `activeChats/{uid}`: 進行中のchatId。終了後はnull。

開始・再開・終了はFirestoreトランザクションで実行します。Firestoreルールでも、両者の占有情報と部屋の状態を一緒に変更することを要求します。直接の書き込みでも他の相手との同時開始、第三者による閲覧・送信は認めません。
プロフィールの実績は会話終了では加算しません。

## 反映前の確認

1. Java 21以降のある環境で、ルートから `npm run test:chat` を実行してください。
2. `firebase/firestore.rules` を対象のFirebaseプロジェクトに反映してください。コンソールのFirestore Database → ルールでファイル全体を貼り付けて公開するか、対象プロジェクトを確認して `firebase deploy --only firestore:rules --project <プロジェクトID>` を実行します。
3. アプリを反映し、別アカウントで開始・送信・終了・再開を確認してください。3人目との開始が双方で制限されることも確認します。

新しい保存先は初回の開始時に自動作成します。手動でコレクションを作る必要はありません。ルールが未反映だと新しい会話の取得・開始は失敗します。

## 以前の投稿チャット

`helpPosts` 以下の投稿チャットは削除・移行していません。新しい一覧には表示されず、旧会話URLはメッセージ一覧に移動します。
投稿ごとに分かれた過去の会話をユーザー単位に統合する場合は、別途移行が必要です。
旧投稿機能のルールやデータは他の機能への影響を避けるため残しています。
