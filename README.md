# Nearu

## 📌 概要

**「今ちょっと困っている人」と「今ちょっと助けられる人」をつなぐアプリです。**

日常生活の中には、

- ベビーカーを階段で運んでほしい
- 切符の買い方が分からない
- 道に迷った
- 大きな荷物があって移動しづらい
- この道を通れるか知りたい

など、「誰かに少しだけ助けてもらえれば解決できる困りごと」があります。

Nearuでは、困っていることを投稿し、近くにいるユーザーから助けてもらうことができます。

助けてもらう方法は、

- 📍 **来てほしい**：近くのユーザーに直接来てもらう
- 💬 **教えてほしい**：チャットで解決方法を教えてもらう

の2種類から選択できます。

さらに、移動に困っている場合には、車椅子・ベビーカー・雨の日・大きな荷物など、ユーザーの状況に合わせた移動しやすいルートを案内します。

---

## 🎯 解決したい課題

街中では、困っていても知らない人に直接声をかけることには心理的なハードルがあります。

一方で、周囲にはその困りごとを簡単に解決できる人がいる可能性があります。

例えば、

- ベビーカーを階段で運ぶのを少し手伝ってほしい
- 券売機の使い方を教えてほしい
- 道に迷ったので行き方を教えてほしい
- 外国語の案内が分からない
- 荷物が多くて階段を避けたい

といった場面です。

Nearuでは、

> **助けてほしい人と、助けられる人をつなぐ**

ことで、小さな困りごとを気軽に解決できる環境を目指します。

また、移動に関する困りごとについては、一般的な「最短ルート」だけではなく、その人の状況に合った移動しやすいルートを案内します。

## ✨ 主な機能

### 🆘 Help投稿

困っている内容を投稿できます。

例：

- ベビーカーを階段で運んでほしい
- 切符の買い方を教えてほしい
- 道に迷った
- 荷物を少し運んでほしい

投稿時に、助けてもらう方法を選択します。

#### 📍 来てほしい

現在地を利用して、近くにいるユーザーに助けを求めます。

#### 💬 教えてほしい

チャットを使って、オンライン上で解決方法を教えてもらいます。

---

### 🗺️ マップ

- 現在地の表示
- 周辺のHelp投稿を表示
- Help投稿の位置を確認
- 目的地の設定
- ルート表示

地図上から近くのHelpを探すことができます。

---

### 💬 チャット

Help投稿を見たユーザーとメッセージでやり取りできます。

「教えてほしい」を選択した場合は、チャットだけで困りごとを解決することもできます。

---

### 🤝 Helpマッチング

Help投稿に対して別のユーザーが「助ける」を選択することでマッチングします。

例：

```text
困っている人
    ↓
Helpを投稿
    ↓
近くのユーザーが確認
    ↓
「助ける」
    ↓
マッチング
    ↓
チャット / 現地でサポート
```

---

## 🛠️ セットアップ

このリポジトリは npm workspaces のモノレポ構成です（`frontend` / `backend` を1つの `package-lock.json` で管理しています）。

**必ずリポジトリのルートで** 以下を実行してください。`frontend/` や `backend/` のフォルダに `cd` して `npm install` すると、ルートと矛盾する `package-lock.json` が新たに作られてしまい、他の人の環境でエラーの原因になります。

```bash
npm install       # 依存関係のインストール（ルートで実行）
npm run dev       # フロント・バックエンドを同時に起動
```
